# postNotes

A simple notes and tasks server, tui, and web ui (with an potential mobile app planned)

<sup>this is work-in-progress</sup>

<p>progress tracking: <strong><code>15</code></strong> of <strong><code>33</code></strong> complete</p>

~~---------------~~  ***`cheat sheet`***  ~~---------------~~

<p><code>[ ]</code> = not started</p>
<p><code>[*]</code> = current task</p>
<p><code>[/]</code> = completed</p>
<p><code>[x]</code> = cancelled</p>
<p><code>[o]</code> = skipped (will do later)</p>
<p><code>[r]</code> = started, returning later</p>
<p><code>[w]</code> = working, but needs refining</p>
<p><code>[u]</code> = "uhhh... well that's a strange bug, I'll come back to this later"</p>
