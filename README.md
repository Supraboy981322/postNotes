# postNotes

A simple notes and tasks server, tui, and web ui (with an potential mobile app planned)

<sup>this is work-in-progress</sup>

~~-----------------~~  ***`progress`***  ~~-----------------~~

<p>progress tracking: **`15`** of `33` complete</p>

~~---------------~~  ***`cheat sheet`***  ~~---------------~~

<p>`[ ]` = not started</p>
<p>`[*]` = current task</p>
<p>`[/]` = completed</p>
<p>`[x]` = cancelled</p>
<p>`[o]` = skipped (will do later)</p>
<p>`[r]` = started, returning later</p>
<p>`[w]` = working, but needs refining</p>
<p>`[u]` = "uhhh... well that's a strange bug, I'll come back to this later"</p>
